## 1. Methodological Principles

This research adheres strictly to empirical, tabula-rasa reinforcement learning principles:
1. **Zero Prior Domain Knowledge:** No opening tables, handcrafted evaluation heuristics, or external engine databases are utilized.
2. **First-Principles Derivation:** All tactical and strategic knowledge must emerge solely from the reward signals generated by terminal game states under self-play tree search.
3. **Rigorous Methodological Separation:** This document outlines the mathematical and algorithmic formulation of the **planned methodology**. No experimental results are claimed prior to empirical execution.

## 2. Mathematical & Algorithmic Formulation

### 2.1 Neural Network Architecture ($f_\theta$)
The agent employs a dual-headed deep convolutional neural network with residual connections parameterized by weights $\theta$:
$$f_\theta(s) = (\mathbf{p}, v)$$
where:
- $s \in \mathbb{R}^{C \times H \times W}$ is the tensor representation of the board state (including piece placements, active player turn, castling rights, en passant, and repetition counts).
- $\mathbf{p} \in \Delta^{|\mathcal{A}|}$ is the probability vector over the action space $\mathcal{A}$ representing prior move probabilities ($P(s, a)$).
- $v \in [-1, 1]$ is a scalar representing the expected game outcome from state $s$ from the perspective of the current player ($+1 = \text{win}, -1 = \text{loss}, 0 = \text{draw}$).

### 2.2 Monte Carlo Tree Search (MCTS)
For each state $s$ encountered during self-play or evaluation, MCTS executes $N_{sim}$ simulations. Each tree node stores statistics:
- $N(s, a)$: Visit count for action $a$ from state $s$.
- $W(s, a)$: Total accumulated action-value.
- $Q(s, a) = \frac{W(s, a)}{N(s, a)}$: Mean action-value.
- $P(s, a)$: Prior probability output by policy network $f_\theta(s)$.

#### Selection Phase:
In state $s$, action $a^*$ is chosen using the Predictor Upper Confidence Bound (PUCT) formula:
$$a^* = \arg\max_a \left( Q(s, a) + U(s, a) \right)$$
$$U(s, a) = c_{puct} \cdot P(s, a) \cdot \frac{\sqrt{\sum_b N(s, b)}}{1 + N(s, a)}$$
where $c_{puct}$ balances exploitation ($Q$) and exploration ($U$). At the root node, Dirichlet exploration noise $\text{Dir}(\alpha)$ is added to priors during self-play:
$$P(s_{root}, a) \leftarrow (1 - \epsilon) P(s_{root}, a) + \epsilon \eta_a, \quad \boldsymbol{\eta} \sim \text{Dir}(\alpha)$$

#### Expansion & Evaluation:
When a leaf node $s_L$ is reached, if it is not terminal, it is evaluated by the neural network $f_\theta(s_L) = (\mathbf{p}, v)$. Legal moves are generated, masked, and initialized with $P(s_L, a) = p_a$ and $N(s_L, a) = 0$.

#### Backup:
Action values along the traversal path are updated:
$$N(s, a) \leftarrow N(s, a) + 1, \quad W(s, a) \leftarrow W(s, a) + v$$

#### Action Execution:
After $N_{sim}$ rollouts, an improved policy search vector $\boldsymbol{\pi}(s)$ is formed from visit counts:
$$\pi(a \mid s) = \frac{N(s, a)^{1/\tau}}{\sum_b N(s, b)^{1/\tau}}$$
where $\tau$ is the temperature parameter ($\tau = 1$ in early plies for exploration, $\tau \rightarrow 0$ later for greedy selection).

## 3. Curriculum Learning Design

To overcome the cold-start credit assignment bottleneck, the agent is guided through a 3-stage curriculum:

```
+-------------------------------------------------------------------------------+
|                        PROGRESSIVE CURRICULUM STAGES                          |
+-------------------------------------------------------------------------------+
| STAGE 1: Minimalist Endgame (KQK / KRK)                                       |
| - State space: Small piece subset on 8x8 grid                                 |
| - Objective: Learn checkmate geometry, edge-pinning, and distance reduction   |
| - Average game length: 5 - 20 plies                                           |
| - Reward density: High (short trajectory to terminal win)                    |
+-------------------------------------------------------------------------------+
                                      |
                                      v (Threshold: Win rate >= 85% on stage)
+-------------------------------------------------------------------------------+
| STAGE 2: Tactical Micro-Board (5x5 / 6x6 Mini-Chess)                          |
| - State space: Reduced grid, standard piece types                             |
| - Objective: Learn piece values, capturing exchanges, tactics, fork/pin       |
| - Average game length: 15 - 40 plies                                          |
| - Reward density: Moderate                                                    |
+-------------------------------------------------------------------------------+
                                      |
                                      v (Threshold: Win rate >= 80% on stage)
+-------------------------------------------------------------------------------+
| STAGE 3: Full Standard 8x8 Chess                                              |
| - State space: Full 64 squares, 32 pieces, standard opening                   |
| - Objective: Global strategy, long-term pawn structures, opening repertoire   |
| - Initialization: Warm-started with convolutional filters learned in Stage 2  |
+-------------------------------------------------------------------------------+
```

### Representation Transfer Strategy
The spatial convolutional filters learned on smaller boards or endgame patterns naturally transfer to 8x8 representations due to translation invariance. Zero-padding and spatial tiling allow the residual feature extractors to generalize spatial tactical motifs (e.g., knight forks, diagonal bishop rays, back-rank mates) from micro-domains into standard chess.

## 4. Loss Function and Optimization

Each self-play game produces training samples $(s_t, \boldsymbol{\pi}_t, z)$, where $z \in \{-1, 0, +1\}$ is the final game outcome.

Parameters $\theta$ are optimized to minimize the composite loss function:
$$\mathcal{L}(\theta) = \frac{1}{|B|} \sum_{(s, \boldsymbol{\pi}, z) \in B} \left[ (z - v_\theta(s))^2 - \boldsymbol{\pi}^\top \log \mathbf{p}_\theta(s) \right] + c \|\theta\|_2^2$$
- **Value Loss:** Mean Squared Error $(z - v_\theta(s))^2$ aligns value prediction with actual game results.
- **Policy Loss:** Cross-Entropy $-\boldsymbol{\pi}^\top \log \mathbf{p}_\theta(s)$ aligns prior move probabilities with improved MCTS visit distributions.
- **Regularization:** $L_2$ weight decay $c \|\theta\|_2^2$ prevents overfitting on small replay buffers.

## 5. Statistical Comparison Methodology

To scientifically validate the primary hypothesis ($H_1$ vs $H_0$):

1. **Sample Efficiency Metric:**
   Let $G_{target}(M)$ denote the total number of self-play games required by method $M$ to reach milestone $M$ (e.g., $75\%$ tactical benchmark accuracy or 1200 Elo). We evaluate the Sample Efficiency Ratio:
   $$\text{SER} = \frac{G_{target}(\text{Baseline})}{G_{target}(\text{Curriculum})}$$
   A value $\text{SER} > 1.0$ indicates superior sample efficiency for the curriculum approach.

2. **Hypothesis Testing:**
   Across $K = 5$ independent seeds, we perform the non-parametric **Mann-Whitney U Test** comparing final Elo ratings and SER between Baseline and Curriculum groups. $p < 0.05$ will be the threshold for rejecting the null hypothesis.

3. **Loss Variance Metric:**
   Training stability is quantified via the rolling window variance of value loss $\sigma^2(\mathcal{L}_{val})$ over 50-iteration intervals. Lower variance signifies greater learning stability.
